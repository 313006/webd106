設計理念

設計理念心得－來去桃花源

這次的設計主題是「來去桃花源」，我的設計理念是希望透過作品帶領大家重新認識桃園，像是展開一場探索之旅，發現桃園不同的文化、景點與特色。我將內容結合電影介紹、探索美食以及發現新桃園，希望讓觀看者不只是看到表面的資訊，而是能更深入了解桃園的魅力，感受到像走進「桃花源」般的新鮮與驚喜。

在電影介紹的部分，我希望透過電影內容與故事背景，讓大家更了解其中想傳達的意義，也增加觀眾對作品的興趣。電影不只是娛樂，更能帶給人不同的感受與想法，因此我希望把電影中的特色與精神呈現出來，讓人看完後對內容留下印象。

在探索美食方面，我認為美食是一個城市的重要特色，因此加入桃園在地美食的介紹，希望讓大家知道桃園不只有景點，也有很多值得品嚐的小吃與特色料理。透過美食探索，可以讓更多人感受到地方文化與人情味，也讓整個主題更加豐富有趣。

而「發現新桃園」則是希望讓大家看見不同於以往印象中的桃園。很多人對桃園的印象可能只有機場或交通便利，但其實桃園也有很多值得探索的地方，像是特色景點、文化故事與自然風景。我希望透過設計讓大家發現桃園新的面貌，感受到這座城市的多元與特色。

在設計過程中，我遇到不少困難，例如如何把電影介紹、美食探索與桃園特色結合在同一個作品中，並讓整體畫面不會顯得太複雜或凌亂。一開始我對版面配置沒有太多想法，常常覺得圖片太多、文字太雜，無法呈現出我想要的感覺。另外，在色彩搭配與主題風格上，也花了很多時間思考，希望能呈現出「桃花源」輕鬆、溫暖與探索感的氛圍。

雖然中間有很多次修改，也曾經因為效果不理想而感到挫折，但透過不斷調整與嘗試，我慢慢學會如何整理資訊、安排版面，以及讓作品更符合主題。這次的設計讓我不只提升了自己的創意與美感能力，也學會耐心與解決問題的方法。我發現設計不只是把畫面做得好看，更重要的是如何把想表達的理念與故事完整呈現，這也讓我在過程中獲得很多成長與收穫。

學習反思:

1.這學期學了那些技能?

這學期我學習到許多網站設計與圖片編輯的技能，也接觸到不同的軟體與平台。首先，我學會使用 Adobe Dreamweaver CS6 製作基本網頁，了解版面配置與網站架構。透過實際操作，讓我更認識網站設計的流程。

另外，我也使用 PhotoImpact 進行圖片編輯與美工設計，學習裁切圖片、調整效果與排版，讓作品看起來更完整。

除此之外，我也接觸到 GitHub，學會上傳與管理作品檔案。雖然一開始操作不太熟悉，但透過練習，我慢慢進步，也提升了解決問題與獨立完成作品的能力。

2.學習過程中遭遇的困難及解決方式?

這學期在學習過程中，我遇到一些困難。例如使用 Adobe Dreamweaver CS6 製作網頁時，剛開始不太熟悉操作方式，常出現排版問題；使用 PhotoImpact 時，也會遇到圖片編輯不理想的情況。

另外，在使用 GitHub 上傳作品時，一開始不太會操作，但我會請教老師與同學，並透過反覆練習慢慢熟悉。雖然過程中有困難，但也讓我學會耐心與解決問題的方法。

3.獲得哪些能力?

透過這學期的學習，我獲得了網站製作、圖片編輯與檔案管理的能力。我學會使用 Adobe Dreamweaver CS6 製作基本網頁，也能利用 PhotoImpact 進行圖片修改與版面設計，讓作品更加完整。

此外，我也學會使用 GitHub 上傳與管理作品檔案。除了軟體操作能力外，我也提升了解決問題、耐心與獨立完成作品的能力，讓自己在面對困難時更有信心。
